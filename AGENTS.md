# Taylor Made financial tools
Preserve existing published URLs and the common forest-green/cream style.
Every current and future tool with user-entered data must provide visible Export backup and Restore backup controls for local JSON files, without requiring Google setup. Validate the complete file before replacing data, confirm replacement, and keep a recoverable previous copy where supported.
Also include Google Drive backup/restore in every new tool, as requested by the owner. Follow DRIVE-BACKUPS.md and use shared/google-drive-backups.js with a validated tool-specific adapter. Never commit personal financial backups or OAuth access tokens/client secrets.
